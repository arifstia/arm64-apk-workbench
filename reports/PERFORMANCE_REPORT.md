## 5. Recommendation

- Use `--mode fast` for CI smoke tests and `--mode normal` for routine audits.
- Use `--mode deep` only when Java source summary is needed; budget ~80 s for a 12 MB APK.
- Always run `install.sh` on a fresh ARM64 machine so the project-local APKTool 3.0.3 JAR, aapt2 wrapper, and framework are created with verified checksums.
